# 网站、Electron、WASM 与网络记录

**简体中文** | [English](03-web-electron-and-network.en.md)

[返回总目录](../README.md)

静态 JavaScript 调查和浏览器运行观察是两条路线。REA 不能通过前端代码恢复未提供的服务端实现。历史 HAR/SAZ/PCAP 是已保存记录，不代表当前网站状态。

## C01

**Electron 功能追踪**

```text
使用 REA 分析 <ASAR 或已提取应用目录> 的 <功能>，从摘要中选择相关模块。
追踪 renderer、preload、contextBridge、IPC 与 main 的连接，再跟踪文件或网络操作；native addon 边界另列。
输出有证据的连接和缺口。不要仅凭通道同名认定调用关系，也不要扫描与本次应用无关的目录。
从实际观察到的通道、API 或节点发起追踪；应用图未覆盖的函数内部逻辑继续读取相关代码。最终解释输入怎样变成结果，并逐段标明静态连接、推测与运行观察，不能把图中的可达性称为已执行。

默认只做静态分析，不运行目标。每项结论引用 Evidence ID 和源位置，区分观察、推导、推测与未知，并说明覆盖缺口。
```
