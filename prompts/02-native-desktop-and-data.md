# 原生程序、桌面应用与本地数据

**简体中文** | [English](02-native-desktop-and-data.en.md)

[返回总目录](../README.md)

深度原生分析需要可用的 Hopper、Ghidra、IDA 等引擎；格式、CPU 与宿主支持须逐项确认。Go/Rust 元数据、PE 资源、托管程序集等有独立静态路线，不应一律先打开原生引擎。

参考：[原生调查](https://github.com/morluto/rea/blob/main/docs/native-investigation.md)、[托管代码](https://github.com/morluto/rea/blob/main/docs/managed-code-analysis.md)、[SQLite](https://github.com/morluto/rea/blob/main/docs/sqlite-databases.md)。
